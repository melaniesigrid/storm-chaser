# Image credits

Every photograph bundled with the storm legends came from Wikimedia Commons.
Licences were read from the Commons API (`extmetadata`) at fetch time rather
than assumed, and only public domain, CC0, CC BY and CC BY-SA files were kept.

Where freely licensed photography of a specific historical storm does not
exist, the image illustrates the phenomenon instead of documenting the event.
The app prints the caption below underneath each photograph so the difference
is visible in the product, not just in this file.
